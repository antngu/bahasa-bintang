# Bahasa Bintang

A dependency-free, frontend-only Bahasa Malaysia practice app for young learners.

## Features

- Child-friendly setup with nickname, optional gender and avatar selection
- 20 large, scrollable avatar choices
- Ten-question starter activity to initialize the learner's skill profile
- English interface by default, with Bahasa Melayu and Simplified Chinese options
- A device-local 4-digit parent PIN gate (initial PIN: `1357`)
- Ten-question daily challenge
- Six beginner-friendly skill areas
- Immediate explanations and optional Malay text-to-speech
- Mastery, XP, coins and streak tracking
- Parent summary and local JSON backup/import
- Offline support after the first visit
- No account, server or analytics

Learner progress is stored only in the browser using `localStorage`. Published lesson content is static and contains no personal information.

## GitHub Pages

The site can be published directly from the root of the `main` branch. No build step is required.
